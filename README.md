# Planner 001

개인 통합 플래너 애플리케이션입니다. 여러 섹션을 하나의 프로젝트로 통합하였습니다.

## 주요 섹션

| 섹션 | 설명 |
|------|------|
| **대시보드** | 전체 현황 요약 — 오늘 할 일, 목표 진행률, 일정, 노트 한눈에 보기 |
| **할 일** | 작업 관리 — 우선순위·상태·마감일·태그 지원, 필터·정렬 기능 |
| **캘린더** | 월간 캘린더 — 할 일 마감일과 시간 블록 시각화, 날짜 클릭 시 일일 플래너 이동 |
| **일일 플래너** | 시간 블록 기반 하루 일정 관리 — 색상 지정, 타임라인 뷰 |
| **목표** | 목표 추적 — 마일스톤 체크리스트, 자동 진행률 계산 |
| **노트** | 메모 관리 — 고정, 태그, 검색, 마크다운 내용 지원 |

## 기술 스택

- **React 18** + **TypeScript**
- **Vite** (빌드 도구)
- **Tailwind CSS** (스타일링)
- **Zustand** (상태 관리, LocalStorage 영속화)
- **date-fns** (날짜 처리)
- **lucide-react** (아이콘)

## 시작하기

```bash
npm install
npm run dev
```

빌드:
```bash
npm run build
```

## 데이터 저장

모든 데이터는 브라우저 **LocalStorage** (`planner-001-store`)에 자동 저장됩니다.
